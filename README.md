A single funny line for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

## The line

> The self-checkout asked if I needed help. I said no. It scanned my dignity twice.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
A `validate()` gate mirrors the bounty gate before writing: 1–140 characters,
UTF-8, not only whitespace, a single line.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
